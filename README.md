# assemble
Read and store OAI data from Open Journal System to create a local journal index system

# installation
1. copy files to your root directory
2. import install.sql to your dbase server
3. set your dbase.php file

# indexing OJS journal
1. provide input text with journal URL (with or without the "oai") and submit
2. it will show the first batch articles DC description and follow the link for the next batch if available
3. continue to add the next batch until finish
